# Point Gomoku｜下注五子棋

[Play online](https://vodghstls.github.io/point-gomoku/) · [English](https://vodghstls.github.io/point-gomoku/en.html)

Unofficial fan-made strategy game inspired by The Devil’s Plan. Four AI levels, local and online friend matches, secret bidding, exactly-five wins, offline PWA.

## Deployment
Upload all files to the existing GitHub Pages root. Keep any Google verification file. Submit https://vodghstls.github.io/point-gomoku/sitemap.xml in Search Console. If changing domains, update canonical, alternate, OG, share and sitemap URLs.

## GitHub Topics

## Online rooms / 好友連線
Create a room to generate a six-character code, copy or share the invitation, then have your friend tap Join. Invitation links prefill the code. Keep the host page open. Rejoin using the same code after a disconnect. Internet and PeerJS signaling are required; restrictive networks may prevent WebRTC connections.

建立房間後分享六碼代碼或邀請連結，好友按加入即可。斷線時可使用相同代碼重新加入，房主須保持頁面開啟。
