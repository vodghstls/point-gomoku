## English

Point Gomoku is a free, fan-made strategy board game inspired by Netflix's *The Devil's Plan*. It combines traditional Gomoku with secret bidding, resource management, and strategic decision-making.

### Features

- Four AI difficulty levels
- Local two-player mode
- Online multiplayer with room codes and invitation links
- Secret bidding system
- Exactly-five winning rule
- Responsive mobile interface
- Installable PWA with offline single-player support
- Automatic local game saving
- English and Traditional Chinese support
- No registration required

## 繁體中文

下注五子棋（Point Gomoku，又稱得分五子棋）是一款受到 Netflix《魔鬼的計謀》啟發的免費線上策略棋類遊戲，結合傳統五子棋、秘密下注、資源管理與心理博弈。

### 遊戲特色

- 四種 AI 難度：簡單、普通、困難、專家
- 單人電腦對戰
- 同裝置雙人對戰
- 跨手機、跨裝置好友連線
- 自動產生房間代碼
- 一鍵分享好友邀請連結
- 秘密下注與分數管理機制
- 恰好五子連線獲勝，六子以上不計
- 手機及電腦介面支援
- PWA 安裝及離線單機遊玩
- 本機棋局自動儲存
- 繁體中文與英文切換
- 免費遊玩，無須註冊帳號

### 如何與好友對戰？

1. 開啟遊戲並選擇線上好友對戰。
2. 建立房間，取得六碼房間代碼。
3. 將房間代碼或邀請連結分享給好友。
4. 好友加入房間後即可開始對戰。

雙方不需要使用相同的 Wi-Fi，但必須保持網路連線。
