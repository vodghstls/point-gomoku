得分五子棋 V3.1
將本資料夾全部檔案上傳 GitHub 公開 repository 根目錄，Settings > Pages > Deploy from a branch > main > / (root) > Save。用 iPhone Safari 開啟部署網址，分享 > 加入主畫面。首次連網載入後可離線單機遊玩。
好友連線：兩人開啟同一版本網址，選好友連線，一人建立房間，另一人輸入相同代碼加入。房主需保持網頁開啟；斷線可重新加入，房主可用原代碼恢復本機保存的房間。使用 PeerJS 公共訊號服務及 WebRTC，無需自行架設伺服器，但部分網路可能無法建立連線，服務亦無可用性保證。房主程式處理結算，技術上可檢視客方下注，不適用於需要防作弊的競賽。
單機自動儲存於瀏覽器，清除網站資料會遺失；未提交的下注不儲存。選位倒數恢復時重置。切換模式會開始新棋局。AI 四級為不同啟發式策略，非經實測排名。
